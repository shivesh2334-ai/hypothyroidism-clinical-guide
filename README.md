# Hypothyroidism Clinical Guide

A standalone clinical learning app based on the supplied Harrison’s Chapter 383 resource. Includes Assessment, Pathophysiology, Learn, Treatment, and Quiz tabs.

## Run locally

Serve this directory with any static HTTP server. No dependencies, API keys, or build step are required.

## Vercel

Import the repository, select Other as the framework, and leave the build command empty. The root directory contains index.html.

For clinical education; clinicians should verify recommendations against current guidance and patient circumstances.
